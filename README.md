# 🏗️ InmoFormwork WMS Enterprise
**Sistema Avanzado de Gestión de Inventarios y Logística para Obras de Construcción**

InmoFormwork WMS (Warehouse Management System) es una plataforma B2B diseñada para erradicar las pérdidas de equipos (encofrados, andamios, puntales) mediante la trazabilidad en tiempo real, control de despachos y liquidación automatizada de penalidades.

## 🚀 Impacto en el Negocio
* **Control Total:** Visibilidad del 100% de la distribución global de activos (Almacén vs. Obra vs. Mantenimiento).
* **Cero Fugas:** Trazabilidad exacta de cada pieza despachada y devuelta, eliminando el "robo hormiga" y extravíos.
* **Liquidación Financiera:** Cálculo automatizado y generación de PDFs legales para el cobro de penalidades por equipos dañados o no devueltos.

## 🛠️ Stack Tecnológico
* **Frontend:** HTML5, CSS3, JS Vanilla (Single Page Application architecture), Bootstrap Icons, Chart.js (Dashboard), SheetJS & html2pdf (Reportes).
* **Backend:** Python + FastAPI (RESTful API, validación Pydantic).
* **Base de Datos:** PostgreSQL alojada en Supabase.
* **Seguridad:** Autenticación mediante tokens JWT y control de acceso basado en roles (Gerente / Almacenero).
* **Despliegue:** GitHub Pages (Client) & Render (Server).
